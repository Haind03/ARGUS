# ARGUS workflow engine (defensive harness)

```
argus case init  --name pc-2026-11 --i-own-this-machine        # scope attestation, case dir, audit chain
argus case run   --case argus-cases/pc-2026-11 --input telemetry.json --workflow full-hunt [--baseline b.json]
argus case findings --case ...                                  # list findings + disposition status
argus case dispose  --case ... --key <finding key> --verdict false_positive --note "Logitech updater, signed, in baseline"
argus case report   --case ... --input telemetry.json           # FINAL only when all high/critical are dispositioned
argus case verify   --case ...                                  # verify SHA-256 hash-chained audit log
argus case optin    --case ... --minutes 60 --reason "confirmed ransomware, user approved containment"
argus case revoke   --case ...
```
(`argus` = `python -I engine/argus_cli.py`)

## Phase schema (`workflows/*.yml`)
| Key | Meaning |
|---|---|
| `id`, `name` | phase identity |
| `hypothesis` | falsifiable statement the phase tests (hunt-methodology) |
| `skills` | skills the agent should load for this phase |
| `tactics` | ATT&CK tactic IDs whose rules run in this phase |
| `rules` | optional subset of rule IDs |
| `gate.require_sections` | telemetry sections that must be present (fail-closed if `blocking: true`) |
| `gate.require_dispositions` | severities that must all be dispositioned (enforced by `case report`) |
| `gate.require_ir_optin` | containment phases: needs an unexpired IR opt-in (enforced by the guard hook) |
| `when` | condition for conditional phases (agent-evaluated) |
| `note` | operator guidance |

Each phase writes `phases/<id>.json` with a **hypothesis verdict**: `supported — investigate` (top score ≥ 60),
`weak leads`, or `not supported by available data` (which is *not* "clean" if collection gaps exist).

## Safety layers
1. **Detect-only engine** — rules read telemetry; nothing in the engine changes the host.
2. **PreToolUse guard hook** (`hooks/pre-tool-guard`) — every Bash/PowerShell command an agent proposes is
   classified; destructive commands are **denied** unless an unexpired IR opt-in exists, and even then the
   user is **asked** per action. Egress (intel uploads) and logging-config changes are always asked.
3. **Gates** — missing collection stops the run; undispositioned high/critical findings block a FINAL report.
4. **Audit chain** — tamper-evident log of every harness action.

`.json` twins of the YAML files are generated by `python -I tools/sync_workflows.py` so the engine runs without PyYAML.
