# Shared references

| Path | Content |
|---|---|
| `ttp-index.json` | single source of truth: ATT&CK technique → tactics, ARGUS rules, reference files (generated) |
| `detection-patterns.md` | cross-tactic heuristics: path classes, LOLBins, parent/child rules, scoring model |
| `false-positive-catalog.md` | common benign software that trips heuristics on personal PCs |
| `yara/vendor/argus-rules.bundle` | 1993 third-party rule files from [Exhume](https://github.com/Haind03/Exhume) + [Unveil](https://github.com/Haind03/Unveil) (signature-base, Elastic, ReversingLabs, ESET, custom); gzip+XOR masked, decoded only in memory; `manifest.json` + `LICENSES/` keep upstream licences |
| `yara/argus_starter.yar` | starter YARA (generated by `tools/build_yara.py`, AV-safe escaped strings) |
| `sigma/*.yml` | starter Sigma rules (process_creation, Defender, Security, WMI) |
| `ioc/*.txt` | local offline IOC lists (hashes, domains, IPs, vulnerable drivers) |
